NEXUS AI is an enterprise platform that enables developers and AI builders to generate, deploy, and operate full‑stack cloud applications using AI‑assisted tools. It offers managed databases, storage, serverless workers, CI‑less deployment to AWS, Google Cloud, and Azure, and a suite of 70+ MCP tools for building, previewing, sharing, and remixing apps. The platform targets indie hackers, startups, and enterprise teams seeking rapid production deployment without managing infrastructure.

**Areas:** Company · AI · Platform · Deployment · Cloud

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for NEXUS AI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
